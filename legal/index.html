Política de privacidad

La web no requiere crear una cuenta y actualmente no utiliza formularios propios para recopilar datos personales. Si contactas por correo electrónico, se tratarán los datos que incluyas voluntariamente únicamente para responder a tu consulta, gestionar soporte o analizar feedback de la aplicación.

La web está alojada mediante infraestructura de terceros y esos proveedores pueden tratar datos técnicos necesarios para prestar el servicio, como direcciones IP o registros de acceso, de acuerdo con sus propias políticas.

La aplicación puede guardar localmente en tu dispositivo información de progreso y configuración, como récords, monedas, coches, mejoras, desbloqueos y preferencias. Estos datos forman parte de una versión de pruebas y pueden reiniciarse.

Para ejercer derechos relacionados con datos que nos hayas enviado directamente por correo, puedes escribir a dj1free@gmail.com.

Publicidad, consentimiento y recompensas

La aplicación Android puede mostrar anuncios recompensados mediante Google AdMob. Cuando la normativa lo exige, el SDK de Google User Messaging Platform (UMP) muestra un mensaje para solicitar o gestionar el consentimiento antes de cargar anuncios.

Para ofrecer, medir y proteger la publicidad, Google y los socios publicitarios participantes pueden tratar datos técnicos y de uso, como la dirección IP, identificadores publicitarios o del dispositivo, información de la aplicación y eventos de interacción. El alcance depende de tus elecciones de consentimiento y de la configuración de tu dispositivo. Consulta la Política de Privacidad de Google.

Puedes revisar o modificar tus opciones de privacidad desde «Privacidad de anuncios» en el menú de la aplicación, cuando esa opción esté disponible.

Usamos RevenueCat para verificar en servidor que un anuncio recompensado se ha completado y para confirmar la recompensa correspondiente dentro del juego. Para esa verificación, RevenueCat puede tratar un identificador seudónimo de usuario, datos técnicos del evento publicitario y el resultado de la validación. El multiplicador de botín solo se concede tras una verificación correcta; cerrar un anuncio por sí solo no concede la recompensa. Consulta la Política de Privacidad de RevenueCat.

Cookies y almacenamiento local

La web oficial no utiliza actualmente cookies publicitarias ni de analítica propias. Se utiliza almacenamiento local del navegador para recordar el idioma seleccionado.

La aplicación utiliza almacenamiento local del dispositivo para conservar progreso y preferencias de juego. Puedes borrar esos datos desde las opciones de almacenamiento del navegador o eliminando los datos de la aplicación.

Los enlaces externos pueden llevar a servicios con sus propias políticas de privacidad y cookies.

  • Las funciones, coches, circuitos, economía y contenidos pueden modificarse o eliminarse antes del lanzamiento.
  • El usuario debe utilizar la aplicación en un dispositivo compatible y bajo su propia responsabilidad respecto a datos locales no respaldados.
  • El feedback enviado puede utilizarse para mejorar el juego, sin obligación de implementar una propuesta concreta.
