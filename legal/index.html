Política de privacidad

La web no requiere crear una cuenta y actualmente no utiliza formularios propios para recopilar datos personales. Si contactas por correo electrónico, se tratarán los datos que incluyas voluntariamente únicamente para responder a tu consulta, gestionar soporte o analizar feedback de la beta.

La web está alojada mediante infraestructura de terceros y esos proveedores pueden tratar datos técnicos necesarios para prestar el servicio, como direcciones IP o registros de acceso, de acuerdo con sus propias políticas.

La beta puede guardar localmente en tu dispositivo información de progreso y configuración, como récords, monedas, coches, mejoras, desbloqueos y preferencias. Estos datos forman parte de una versión de pruebas y pueden reiniciarse.

Para ejercer derechos relacionados con datos que nos hayas enviado directamente por correo, puedes escribir a dj1free@gmail.com.

Cookies y almacenamiento local

La web oficial no utiliza actualmente cookies publicitarias ni de analítica propias. Se utiliza almacenamiento local del navegador para recordar el idioma seleccionado.

La beta utiliza almacenamiento local del dispositivo para conservar progreso y preferencias de juego. Puedes borrar esos datos desde las opciones de almacenamiento del navegador o eliminando los datos de la PWA instalada.

Los enlaces externos pueden llevar a servicios con sus propias políticas de privacidad y cookies.

Condiciones de la beta

  • La beta se ofrece para pruebas y puede contener errores, cierres inesperados, funciones incompletas o cambios de equilibrio.
  • No se garantiza la conservación del progreso durante la fase beta.
  • Las funciones, coches, circuitos, economía y contenidos pueden modificarse o eliminarse antes del lanzamiento.
  • El usuario debe utilizar la beta en un dispositivo compatible y bajo su propia responsabilidad respecto a datos locales no respaldados.
  • El feedback enviado puede utilizarse para mejorar el juego, sin obligación de implementar una propuesta concreta.
