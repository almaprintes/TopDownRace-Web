# Assets de la web · Top Down RACE

Estructura preparada para material visual definitivo.

- `hero/`: imagen/pantalla inicial y material principal de portada.
- `circuits/`: imágenes promocionales o reencuadradas de circuitos.
- `story/`: cómic y material de la historia de creación del juego.

## Nombres recomendados

### Hero
- `hero/hero-main.webp` — pieza principal de portada.
- `hero/game-screen.webp` — captura inicial del juego, si se usa separada.

### Circuitos
- `circuits/<slug>-web.webp` — por ejemplo `karting-tenerife-web.webp`.
- Mantener, si es posible, una relación 16:9 para bloques panorámicos.

### Historia
- `story/origin-comic.webp` — cómic completo.
- Si se divide para móvil: `origin-comic-01.webp`, `origin-comic-02.webp`, etc.

Preferir WEBP de buena calidad para publicación. Los originales pueden conservarse fuera de esta carpeta si se necesita archivo maestro.
